## [0.1.1] - 2026-10-07

### Added

- `mcpName` and `server.json` for the official MCP Registry, as `io.github.azabroflovski/mxik`.

## [0.1.0] - 2026-10-07

### Added

- MCP server over stdio with tools `search_mxik_codes`, `filter_mxik_codes`, `search_product_types`, `get_mxik_card`, `browse_catalog` and `get_tax_benefit`.
- In-memory cache of results for an hour.
