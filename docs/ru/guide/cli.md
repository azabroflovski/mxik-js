# CLI

В пакет `mxik` входит утилита командной строки. Запустить без установки:

```sh
npx mxik search кофе
```

Или установить глобально, чтобы появилась команда `mxik`:

```sh
npm i -g mxik
```

## Команды {#commands}

| Команда                 | Что делает                                            |
| ----------------------- | ----------------------------------------------------- |
| `search <query>`        | Полнотекстовый поиск по названию, бренду или коду     |
| `filter`                | Поиск по полям: `--brand`, `--barcode`, `--text`, `--code` |
| `subpositions <query>`  | Поиск по типу товара, коды без бренда                 |
| `card <code>`           | Карточка кода: штрихкод, льгота, упаковки             |
| `get <code>`            | Код с названиями на русском и узбекском               |
| `children [code]`       | Следующий уровень каталога, без кода — группы         |
| `stats`                 | Сколько в каталоге групп, классов, …, кодов           |
| `units`                 | Единицы измерения                                     |
| `tax-benefits`          | Налоговые льготы                                      |

## Опции {#options}

| Опция             | Описание                             |
| ----------------- | ------------------------------------ |
| `--lang <ru\|uz>` | Язык названий, по умолчанию `ru`     |
| `--page <n>`      | Номер страницы, начиная с 1          |
| `--size <n>`      | Размер страницы, по умолчанию 20     |
| `--json`          | Вывести JSON как есть                |
| `--help`, `-h`    | Показать справку                     |
| `--version`, `-v` | Показать версию                      |

## Примеры {#examples}

```sh
$ mxik search Maccoffee --size 2
00901001001048023  Молотый (порошкообразный) кофе: Maccoffee, в пакет 3в1 20г
00901001001048019  Молотый (порошкообразный) кофе: Maccoffee, pho 3in1 24г

Page 1 of 14, 28 total
```

```sh
$ mxik filter --barcode 6934177746536
08504003009011001  Зарядные устройства и блоки питания (всех видов и для всех устройств): XIAOMI, Mi Robot Vacuum-mop auto-empty station

Page 1 of 1, 1 total
```

```sh
$ mxik children 00901001
00901001001  Молотый (порошкообразный) кофе  305
00901001002  Зерновой (немолотый) кофе  90
00901001004  Сублимированный кофе  30

Page 1 of 1, 3 total
```

Результаты идут в stdout, а строка о страницах — в stderr, поэтому при перенаправлении остаются только результаты:

```sh
mxik search кофе --size 100 | cut -d ' ' -f 1
mxik card 00901001001048023 --json | jq .internationalCode
```

## Коды выхода {#exit-codes}

| Код  | Значение                                      |
| ---- | --------------------------------------------- |
| `0`  | Успех                                         |
| `1`  | Ничего не найдено, нет такого кода, ошибка API |
| `2`  | Неверный вызов: неизвестная команда или опция |
