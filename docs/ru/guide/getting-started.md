# Начало работы

ИКПУ (MXIK) — национальный каталог товаров и услуг Узбекистана. Его 17-значные коды указываются в счетах-фактурах и других электронных учётных документах, а ищут их на [tasnif.soliq.uz](https://tasnif.soliq.uz).

`mxik` обращается к тому же API, что и сайт, поэтому коды можно искать прямо из своего кода: по названию, штрихкоду, бренду или номеру сертификата.

::: info Это не официальный SDK
Библиотека не связана с Налоговым комитетом Узбекистана и tasnif.soliq.uz. Она использует публичный API сайта, у которого нет документации и который может измениться без предупреждения. Если ответ вдруг стал выглядеть иначе, [создайте issue](https://github.com/azabroflovski/mxik-js/issues).
:::

::: warning Хостинг за пределами Узбекистана
API может не отвечать серверам за пределами Узбекистана. Перед деплоем за рубежом проверьте, что сервер достучится до `tasnif.soliq.uz`. Если нет, направьте запросы через прокси с помощью опции [`baseURL`](./options#proxy).
:::

## Установка {#install}

::: code-group

```sh [npm]
npm i mxik
```

```sh [pnpm]
pnpm add mxik
```

```sh [yarn]
yarn add mxik
```

```sh [bun]
bun add mxik
```

:::

В Deno импортируйте как `npm:mxik`.

## Первый запрос {#first-request}

```ts
import { createMxik } from 'mxik'

const mxik = createMxik()

const { items, total } = await mxik.search('Maccoffee')
```

`items` — первая страница результатов, по умолчанию 20 штук, `total` — сколько их всего. У каждого элемента есть код, название и место в иерархии каталога:

```ts
items[0].mxikCode // '00901001001048023'
items[0].name // 'Молотый (порошкообразный) кофе: Maccoffee, в пакет 3в1 20г'
items[0].groupName // 'КОФЕ, ЧАЙ И СПЕЦИИ'
```

Если код уже известен, получите его полную карточку:

```ts
const details = await mxik.get('00901001001048023')

details?.subPositionNameRu // 'Молотый (порошкообразный) кофе'
details?.subPositionNameUz // 'Майдаланган (кукунсимон) кофе'
```

Если кода не существует, `get()` вернёт `null`.

## Где работает {#where-it-runs}

- Node.js 20 и новее, Bun и Deno.
- Браузеры: API разрешает кросс-доменные запросы.
- Edge-окружения и всё, где есть `fetch`. Можно также [передать свой](./options#custom-fetch).

В пакете есть сборки ESM и CommonJS с декларациями типов:

```ts
import { createMxik } from 'mxik'
// или
const { createMxik } = require('mxik')
```
