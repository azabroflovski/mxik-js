# Поиск

Найти коды можно четырьмя способами, и ещё одним — получить отдельный код:

| Метод                 | Когда у вас есть                         |
| --------------------- | ---------------------------------------- |
| `search(query)`       | Текст: название товара, слово, код       |
| `filter({ brand })`   | Название бренда                          |
| `filter({ barcode })` | Штрихкод с упаковки                      |
| `dvCert(number)`      | Номер сертификата                        |
| `get(code)`           | Точный 17-значный код                    |

## По тексту {#by-keyword}

```ts
const page = await mxik.search('Maccoffee')
```

Ищет по названиям, брендам, атрибутам и кодам. Работает и кириллица, и латиница: `'кофе'` и `'kofe'` находят похожие результаты. Элементы имеют тип [`SearchItem`](/ru/api#types).

## По полям {#by-fields}

`filter()` ищет по конкретным полям. Элементы имеют тип [`CatalogItem`](/ru/api#types).

```ts
await mxik.filter({ brand: 'Samsung' })
await mxik.filter({ barcode: '6934177746536' })
await mxik.filter({ text: 'vacuum', brand: 'Xiaomi' })
```

| Фильтр    | Что ищет                                         |
| --------- | ------------------------------------------------ |
| `text`    | Слова в названии, бренде, атрибутах и коде       |
| `brand`   | Название бренда, частично и без учёта регистра   |
| `code`    | Точный 17-значный код                            |
| `barcode` | Штрихкод товара (GTIN)                           |

::: info Примечание
У `barcode` приоритет: если он задан, API игнорирует остальные фильтры.
:::

## По номеру сертификата {#by-certificate-number}

```ts
await mxik.dvCert(certNumber)
```

Возвращает коды, связанные с сертификатом, в виде [`CatalogItem`](/ru/api#types).

## Отдельный код {#a-single-code}

```ts
const details = await mxik.get('00901001001048023')

if (details) {
  details.subPositionNameRu // 'Молотый (порошкообразный) кофе'
  details.packageNames // единицы упаковки, например 'шт. (пачка) 20 грамм'
}
```

Возвращает [`MxikDetails`](/ru/api#types) с названиями на русском и узбекском или `null`, если кода не существует.

У кодов бывают ведущие нули, поэтому храните их строками. Чтобы проверить формат до запроса, используйте `isMxikCode()`:

```ts
import { isMxikCode } from 'mxik'

isMxikCode('00901001001048023') // true
isMxikCode('901001001048023') // false
```

## Страницы {#pages}

`search()`, `filter()` и `dvCert()` возвращают по одной странице:

```ts
const page = await mxik.search('кофе', { page: 2, size: 50 })
```

| Поле      | Описание                                 |
| --------- | ---------------------------------------- |
| `items`   | Результаты на этой странице              |
| `total`   | Результаты на всех страницах             |
| `page`    | Номер страницы, начиная с 1              |
| `size`    | Размер страницы                          |
| `hasNext` | Есть ли следующая страница               |

По умолчанию на странице 20 результатов. Это меняется для отдельного запроса через `size` или для всего клиента через [`pageSize`](./options).

## Все результаты {#all-results}

`searchAll()` и `filterAll()` сами проходят по всем страницам. Следующая страница запрашивается по ходу перебора, поэтому если остановиться раньше, лишних запросов не будет:

```ts
for await (const item of mxik.filterAll({ brand: 'Xiaomi' })) {
  if (item.internationalCode === barcode)
    break
}
```

Чем больше `size`, тем меньше запросов. API принимает как минимум 500:

```ts
mxik.searchAll('кофе', { size: 500 })
```

## Язык {#language}

Названия в результатах `search()`, `filter()` и `dvCert()` по умолчанию на русском. На узбекский (кириллица) можно переключить для отдельного запроса или для всего клиента:

```ts
await mxik.search('кофе', { lang: 'uz' })

const mxik = createMxik({ lang: 'uz' })
```

`get()` от языка не зависит: в карточке есть все названия на обоих языках, например `subPositionNameRu` и `subPositionNameUz`.
