# MCP-сервер

`mxik-mcp` — [MCP](https://modelcontextprotocol.io)-сервер: с ним Claude, Cursor и другие ИИ-ассистенты сами ищут коды ИКПУ. Спросите «найди ИКПУ по этому штрихкоду», и ассистент сам обратится к API.

Это отдельный пакет, поэтому библиотека `mxik` остаётся без зависимостей.

## Подключение {#setup}

Нужен Node.js 20 или новее на машине, у которой есть доступ к tasnif.soliq.uz.

::: code-group

```sh [Claude Code]
claude mcp add mxik -- npx -y mxik-mcp
```

```json [Claude Desktop, Cursor]
{
  "mcpServers": {
    "mxik": {
      "command": "npx",
      "args": ["-y", "mxik-mcp"]
    }
  }
}
```

:::

Для Claude Desktop JSON добавляется в `claude_desktop_config.json`, для Cursor — в `.cursor/mcp.json`.

## Инструменты {#tools}

| Инструмент             | Что делает                                                          |
| ---------------------- | ------------------------------------------------------------------- |
| `search_mxik_codes`    | Полнотекстовый поиск по названию, бренду или коду                   |
| `filter_mxik_codes`    | Поиск кодов по штрихкоду, бренду, словам или точному коду           |
| `search_product_types` | Общие коды типа товара, без бренда                                  |
| `get_mxik_card`        | Карточка кода: названия в каталоге, штрихкод, льгота, упаковки      |
| `browse_catalog`       | Обход дерева каталога от групп до кодов                             |
| `get_tax_benefit`      | Льгота по id вместе с документом, который её устанавливает          |

Инструменты возвращают компактный JSON без пустых полей, чтобы экономить контекст модели. Результаты кешируются в памяти на час.

## Примеры запросов {#example-prompts}

- Найди ИКПУ для Maccoffee 3в1 в пакетиках по 20 г
- Какой ИКПУ у штрихкода 6934177746536?
- Какая льгота действует для кода 03004999096001001?
- Покажи субпозиции класса «Кофе»
